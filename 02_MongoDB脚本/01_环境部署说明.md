# 任务一 · 环境部署说明（ST-1.1 / ST-1.2）

> 目标：完成 MongoDB 安装与配置，让 `mongod` / `mongosh` 在任意目录可直接执行，
> 并启动一个端口为 **27017**、数据目录自定义的 MongoDB 实例。

## 1. 安装 MongoDB（Windows）

1. 到 MongoDB 官网下载 **MongoDB Community Server**（建议 8.x 或 9.x，本项目实测 **9.0.2**，Windows x64 的 `.msi` 安装包）。
2. 运行 `.msi`，选择 **Complete**（完整安装）。
   - 若安装向导出现 **"Install MongoDB as a Service"** 选项，可勾选（作为 Windows 服务开机自启）；
   - 本实训建议**先不勾选**服务方式，改为手动用命令行启动，便于指定自定义数据目录和端口。
3. 记下安装目录，默认类似：
   - `C:\Program Files\MongoDB\Server\9.0\`
   - 其中 `bin\` 目录下包含 `mongod.exe`（服务器）。`mongosh.exe` 与 `mongoimport.exe` 分别由 MongoDB Shell / Database Tools 提供。

## 2. 配置环境变量（ST-1.2）

把 `bin` 目录加入系统 `PATH`：

1. 右键「此电脑」→ 属性 → 高级系统设置 → 环境变量。
2. 在「系统变量」中找到 `Path`，点「编辑」→「新建」。
3. 加入一行：`C:\Program Files\MongoDB\Server\9.0\bin`（改成你的实际路径）。
4. 确定保存。

**验证**：新开一个终端（cmd 或 PowerShell），输入：

```bash
mongod --version
mongosh --version
```

能打印版本号即配置成功。

## 3. 创建自定义数据目录并启动服务（ST-1.1）

在任意位置创建数据目录（例如项目目录下）：

```bash
mkdir C:\mongodb-data
```

启动 `mongod`，指定端口 27017 与自定义数据目录：

```bash
mongod --dbpath "C:\mongodb-data" --port 27017 --logpath "C:\mongodb-data\mongod.log" --logappend
```

参数说明：

| 参数 | 作用 |
|------|------|
| `--dbpath` | 指定数据目录（自定义路径） |
| `--port` | 指定端口，默认 27017 |
| `--logpath` | 日志文件（便于截图启动完成标志） |
| `--logappend` | 日志追加，不覆盖 |

> **注意**：启动后该终端窗口会一直占用（服务运行中），不要关闭；另开一个终端用 `mongosh` 连接。

## 4. 验证启动成功

1. 观察启动日志，找到启动完成标志行，例如：
   ```
   {"t":{...},"s":"I","c":"NETWORK","msg":"Waiting for connections","attr":{"port":27017,"ssl":"off"}}
   ```
2. 另开终端连接：
   ```bash
   mongosh "mongodb://localhost:27017"
   ```
3. 看到 `test>` 提示符，说明实例可正常访问。

## 5. 记录的关键参数（写入报告）

| 项目 | 值 |
|------|-----|
| 端口 | 27017 |
| 数据目录 | `C:\mongodb-data`（自定义） |
| 日志文件 | `C:\mongodb-data\mongod.log` |
| 连接串 | `mongodb://localhost:27017` |

## 6. 常用命令备忘

| 命令 | 作用 |
|------|------|
| `mongod --dbpath <路径>` | 启动数据库服务器 |
| `mongosh` | 启动客户端（交互式 shell） |
| `mongoimport --db library --collection books --file books.txt` | 导入数据文件 |
| `mongoexport --db library --collection books --out books.json` | 导出集合数据 |

## 7. 附：导入三个数据文件（供任务二使用）

在**系统终端**（非 mongosh 内）执行：

```bash
cd 图书情报检索与统计平台
mongoimport --db library --collection books       --file data/books.txt
mongoimport --db library --collection readers     --file data/readers.txt
mongoimport --db library --collection borrow_logs --file data/borrow_logs.txt
```

> `data/*.txt` 为一行一个 JSON 文档（日期用 `{"$date": "..."}` 扩展 JSON），
> `mongoimport` 会自动识别为 Date 类型。
